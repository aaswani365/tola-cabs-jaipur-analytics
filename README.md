## 📌 Project Overview

**TOLA Cabs Jaipur Analytics** is an end-to-end Data Analytics project developed using **SQL and Microsoft Power BI**.

The project analyzes cab booking data from **Jaipur city** to uncover business insights related to ride performance, revenue trends, customer behaviour, vehicle performance, and operational efficiency.

The objective of this project is to transform raw booking data into meaningful dashboards and actionable insights that can help improve business decision-making.

---

# 🎯 Business Objectives

The key objectives of this project are:

* Analyze overall cab booking performance
* Understand revenue generation patterns
* Identify peak demand periods
* Analyze customer booking behaviour
* Evaluate vehicle category performance
* Track ride completion and cancellation trends
* Build an interactive Power BI dashboard for business stakeholders
